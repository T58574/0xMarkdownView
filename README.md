# Notion Markdown Preview (`0xMarkdownView`)

Расширение для VS Code, Antigravity, Cursor и VSCodium, добавляющее кнопку **"Просмотр Md"** для любого `.md` файла с открытием предпросмотра в стиле Notion.

## 🌟 Возможности

- **Кнопка "Просмотр Md"** прямо в верхней панели редактора `.md` файлов (`editor/title`).
- **Стилизация Notion**: современная типографика, блочная верстка, чистые отступы.
- **Callout-блоки**: подсвеченные информационные блоки с иконками (`::: note`, `::: warning`, `::: tip`, `::: error`, `::: info`).
- **Раскрывающие списки (Toggles)**: поддерживают сворачиваемые секции (`::: toggle Заголовок`).
- **Интерактивные чекбоксы (Task Lists)**: стилизованный список задач (`- [ ]`, `- [x]`).
- **Блоки кода**: с меткой языка программирования и кнопкой **"Копировать"**.
- **Интерактивное Содержание (TOC)**: боковая панель с плавной навигацией по заголовкам.
- **Диаграммы Mermaid**: авто-рендеринг блочных схем и диаграмм.
- **Математика KaTeX**: поддержка формул (`$...$` и `$$...$$`).
- **Live-Update**: мгновенный синхронный предпросмотр при редактировании текста.
- **Синхронизация темы**: поддержка светлой и тёмной темы VS Code с переключателем.

## 🚀 Использование

1. Откройте любой файл Markdown (`.md`).
2. В верхнем правом углу вкладки нажмите кнопку **"Просмотр Md"** (или используйте сочетание клавиш / палитру команд `Notion Preview: Просмотр Md`).
3. Рядом откроется вкладка предпросмотра в стиле Notion.
